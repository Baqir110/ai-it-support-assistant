# Peripheral and Hardware Issues

## Symptoms

- Printer not printing / stuck in queue
- External monitor not detected
- USB devices not recognized
- Webcam or microphone not working in calls

## Printer Troubleshooting

1. Confirm the printer is powered on and online (not paused).
2. Check the physical connection (USB/network) and that it appears in the
   OS printer list.
3. Clear the print queue and resend the job.
4. Check for paper jams or low toner/ink.
5. Update or reinstall the printer driver.

## Monitor / Display Troubleshooting

1. Check the cable connection (HDMI/DisplayPort) at both ends.
2. Try a different port or cable to isolate a faulty component.
3. Update the GPU driver.
4. Use the OS display detection ("Detect" in Windows Display Settings).

## USB / Peripheral Troubleshooting

1. Try a different USB port, ideally directly on the motherboard rather
   than through a hub.
2. Check Device Manager for a yellow warning icon on the device.
3. Reinstall or roll back the device driver.

## When to Escalate

Escalate for hardware that fails across multiple ports/cables/drivers,
which usually indicates a genuine hardware fault requiring replacement.
